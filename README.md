Meus Primeiros Passos no Front-End

Olá! Seja bem-vindo ao repositório do meu projeto de **Card de Apresentação**. Este foi um dos projetos mais importantes e divertidos que fiz até agora, pois foi onde coloquei a mão na massa para consolidar meus conhecimentos básicos de **HTML5** e **CSS3**. 

O grande objetivo aqui foi aprender a dar "pequenos passos" na programação para construir uma base sólida e evoluir na minha carreira em tecnologia.

---

O que eu aprendi realizando este projeto?

Construir esse card me fez entender que o desenvolvimento web vai muito além de apenas "fazer as coisas aparecerem na tela". Eu pude praticar conceitos fundamentais que todo desenvolvedor front-end precisa dominar:

1. Semântica no HTML5
Aprendi a importância de usar as tags certas nos lugares certos para que o navegador e os leitores de tela entendam a estrutura do meu site. No código, organizei tudo usando:
* `<main>` para o conteúdo principal.
* `<article>` para isolar o card do restante da página.
* `<header>`, `<section class="card-body">` e `<footer>` para dividir o topo, o corpo e o rodapé do card de forma lógica.
* *Correção de bugs:* Durante o desenvolvimento, aprendi a prestar muita atenção no fechamento das tags (como o aninhamento correto entre `section` e `article`) para não quebrar o layout!

 2. Estilização Moderna e Alinhamento com Flexbox
O CSS foi a parte onde a mágica aconteceu. Com ele, eu aprendi a entender o **Flexbox**:
* Usei `display: flex`, `justify-content: center` e `align-items: center` no corpo da página para fazer o card ficar perfeitamente centralizado na tela, independente do tamanho do monitor.
* Também usei Flexbox dentro do próprio card (`flex-direction: column`) para empilhar os elementos (imagem, texto e rodapé) de forma organizada.

3. Animações com CSS (`@keyframes`)
Essa com certeza foi a parte mais legal! Eu queria que o fundo da tela fosse dinâmico, então criei um gradiente linear colorido (`linear-gradient`) e usei as propriedades `background-size: 400% 400%` junto com `@keyframes`. 
Isso fez com que o fundo ganhasse uma animação suave que move as cores continuamente, dando um efeito super moderno e vivo ao projeto.

 4. Responsividade e Ajustes de Imagem
Entendi como controlar o comportamento das imagens usando `max-width: 100%` e `object-fit: cover` para garantir que o banner do card se adapte bem e não quebre em telas menores, além de aplicar `border-radius` para deixar as bordas arredondadas e elegantes.


 Tecnologias Utilizadas

* **HTML5** (Estruturação semântica)
* **CSS3** (Estilização, Flexbox, Animações e Efeitos de Sombra/Shadow)
* Imagem gerada por Inteligência Artificial (Gemini)---
